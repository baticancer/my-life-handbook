# 生活 / Life

记录让「日子」过得更清楚、更舒服的一切。

## 这里该记什么

- 💪 **健康**：运动记录、睡眠、饮食、体检
- 💰 **财务**：预算、记账、资产、订阅清单
- 📅 **日程**：重要日期、年度计划、旅行
- 👪 **人际**：家人朋友的重要信息、待办
- 🧺 **清单**：购物清单、待办、想尝试的事

## 建议文件

- `健康.md`
- `财务.md` / `订阅清单.md`
- `年度计划.md`
- `旅行/` —— 每次出行一个文件
- `清单.md`

## 怎么记

- 财务类只记汇总与提醒，明细交给记账 App。
- 健康类可配合 `../habits/` 的打卡表一起看。
- 隐私内容注意：本仓库为私有，但仍避免写入明文密码 / 证件号。
