# 习惯 / Habits

把想长期做的事，变成可追踪的系统。

## 这里该记什么

- 🌅 **晨间例行 / 晚间例行**：每天固定动作清单
- ✅ **习惯打卡**：用 `habit-tracker.md` 模板按月打卡
- 🔁 **复盘**：哪些习惯坚持了、哪些放弃了、为什么
- 📊 **指标**：体重、阅读量、运动时长等可量化数据

## 建议文件

- `例行.md` —— 晨间 / 晚间流程
- `habit-tracker.md` —— 月度打卡表（见下方模板说明）
- `复盘.md` —— 习惯复盘

## 怎么记

- 一次只加 1–2 个新习惯，别贪多。
- 打卡用「✅ / ❌ / —（休息）」即可，降低记录成本。
- 每月底用 `../templates/monthly-review.md` 回顾。

---

## habit-tracker.md 用法

复制 `habit-tracker.md` 到 `habits/2026-09-习惯打卡.md` 这类文件，按列填：

| 日期 | 早起 | 运动 | 阅读 | 记账 | 备注 |
|------|------|------|------|------|------|
| 01   | ✅   | ✅   | ❌   | ✅   |      |
| 02   | ✅   | —    | ✅   | ✅   | 出差 |
