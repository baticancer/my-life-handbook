# 工作 / Work

记录一切与「职业成长」和「产出」相关的内容。

## 这里该记什么

- 🎯 **目标**：季度 / 年度 OKR、关键结果
- 📁 **项目**：进行中项目的背景、决策、链接、复盘
- 📝 **周报 / 月报**：可复制 `../templates/` 的结构
- 📚 **学习笔记**：读书、课程、技术研习
- 🧰 **技能清单**：已掌握 / 在学 / 想学
- 💡 **灵感与想法**：产品点子、改进提案

## 建议文件

- `目标.md` —— 长期目标与拆解
- `项目/` —— 每个项目一个文件或子目录
- `学习/` —— 读书/课程笔记
- `技能清单.md`

## 怎么记

- 结论先行，细节后置。
- 决策类内容务必写「背景 + 决定 + 原因」，方便日后复盘。
- 链接优先放原文地址，少搬运。
