# 爱好 / Hobbies

记录让我投入、放松、有成就感的事。

## 这里可以有什么

- 🏃 运动：跑步、健身、球类（配 `../habits/` 打卡）
- 📷 摄影：作品、参数、心得
- 🎵 音乐：在学乐器、歌单、现场
- ✍️ 手工 / 创作：模型、绘画、写作
- 🌱 任何「费时间但开心」的事

## 建议结构

每个爱好一个子目录或一个文件，例如：

- `摄影/`
- `跑步.md`
- `阅读.md`

## 怎么记

- 放下「有用没用」的评判，记录过程和感受即可。
- 可贴图（注意仓库体积，大图建议外链或压缩）。
- 与 `../habits/` 联动：把爱好变成习惯，更容易坚持。
