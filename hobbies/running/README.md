## 三、核心结论速览（一句话每条）

1. **腕式光学心率表会失准**：最怕贴合松、手臂加速度乱、冷启动没锁定；正确佩戴 + 开跑前静候 30–60 秒可避免绝大多数假高。
2. **发烧即全停**：带病上量有心肌炎风险（尤其脂蛋白(a)高者），丢一周有氧量不影响破三目标，宁少练不赌病。
3. **配速分区看"主课段"**：用全程平均会丢真——必须把热身/恢复/冷身段剥离，只统计主课段的技术指标（步频/触地/步幅）。
4. **步幅是破三最大杠杆**：你 E 跑 1.00m，破三需 1.20m+；送髋/蹬伸做功比单纯多倒腿更重要。
5. **体重有下限**：≥74.0kg 正常档；跌破 73 启动警戒、72 以下红线、<72 硬停；口报"斤"需 ÷2。
6. **他人数据接口拉不到**：佳明国行社交模块屏蔽，只能靠 App；想深度分析请对方导 FIT 或发截图。

## 四、脚本用法

```bash
# 拉取最近 N 天数据（需先有本机佳明 token）
export GARMIN_TOKEN_DIR=/path/to/your/garmin-token
export GARMIN_DISPLAY_NAME=你的佳明昵称
TMPDIR=/tmp <python3> scripts/fetch_garmin.py 14 out.json

# 配速分区分析（方案 C 默认，--seg 出分段明细）
<python3> scripts/analyze_pace_zones.py 30 分区.json --scheme C --seg
```

依赖：`pip install garth`（国行域用 `garth.configure(domain='garmin.cn')` ）。
