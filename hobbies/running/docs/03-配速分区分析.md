# 配速分区分析（阈值速度法）

> 来源：2026-09-15 上个月配速分区、2026-09-16 用户纠错（平均会失真）、2026-09-19 固化脚本。

## 一、为什么要"按阈值速度"分区

传统"看平均配速"会丢真。曹宁 2026-09-16 一场 10.65km，全程平均显示"快跑区 52%"——但分段拆解发现是 5×1.6km 重复跑（I 课），走路恢复段稀释了平均，主课段技术其实破三级、身体可接受。**平均数值会误导判断。**

## 二、分区方案（边界随 VDOT 刷新）

秒/km；`<下界`=快跑，`下界~上界`=中间，`>上界`=慢跑。曹宁当前 VDOT≈46（T=4:33 / I=4:15），**默认方案 C**（贴合绍兴冲 3:15 的有氧主导目标）。

| 方案 | 慢跑 | 中间 | 快跑 | 适用 |
|---|---|---|---|---|
| A 阈值二分 | >4:33 | 4:15–4:33 | <4:15 | T/I 二分 |
| B 突出 M | >5:00 | 4:33–5:00 | <4:33 | 突出 M 配速 |
| **C 80:20（默认）** | **>4:45** | **4:20–4:45** | **<4:20** | 有氧主导，控失控 |

> 东营 10/18 实测 VDOT 后同步刷新全部边界。

## 三、分段判读法（核心：剥离非主课段）

用 `analyze_pace_zones.py --seg` 把每堂课按 **热身 / 主课 / 恢复 / 冷身** 拆开：
- 阶段识别：步频 ≥150 且 配速 ≤4:45 → 主课；主课前 → 热身；主课后 → 冷身；之间 → 恢复（含走路段）。
- **技术指标（步频/触地/步幅）与分区占比，均给"整课"与"仅主课段"两版**。判读看主课段，不被恢复走段稀释。
- 每段带**气温（directAirTemperature）与爬升（directElevation）**：心率判读必须结合——平路高温下 HR 虚高，不能单看数字。

## 四、控"失控"四步

出现"快跑区占比异常高 / 平均配速偏快"时，按顺序排查：
1. 是不是主动 I 课升级（如 9/09、9/16）→ 主课段 100% 快跑区是正常的，非失控。
2. 是不是分段被平均掩盖（恢复走段拉低技术均值）→ 看主课段视角。
3. 是不是心率/配速被气温爬升推高 → 结合环境修正判读。
4. 真·失控仅一种：计划 E 跑却跑成 Z4（如 9/06 长距离）→ 当周补纪律。

## 五、结构目标

- **80:20 原则**：快跑（高质量）占比参考 ~9%；曹宁上月曾达 22%（约为 2.4 倍），整改后盯中间区升到 20%+、快跑压回 12% 内。
- 双阈值（挪威法）补中间区：工作日只能晚跑故单节内 LT1+LT2 两段，喂中间区、质量锁 ~20–25%，不增质量日、不破 80:20。

## 六、用法

```bash
<python3> scripts/analyze_pace_zones.py 30 分区.json --scheme C --seg
```

逐点接口：`/activity-service/activity/{id}/details?maxChartSize=4000`
分段接口：`/activity-service/activity/{id}/splits`（lapDTOs）
