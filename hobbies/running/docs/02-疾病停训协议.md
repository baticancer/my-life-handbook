# 疾病 / 发烧停训协议

> 来源：2026-09-23 风热感冒发烧 38.3°C、2026-09-28 轻微感冒复评，固化为可复用协议。

## 一、硬规则：发烧（≥37.5°C）即全停

所有跑步、高强度力量、间歇**全部取消**，含当周长距离。带病上量有心肌炎风险。

**为什么（尤其对你）**：
- 运动时心输出量翻倍、体温再升，病毒易侵袭心肌 → 心肌炎。
- 你体检：**脂蛋白(a) 678（遗传性心脏风险）+ 血小板 114 偏低 + 心电图窦缓** → 更不允许赌。
- 丢一周有氧量**不影响**破三目标（东营半马距生病约 25 天）；强行练出心肌炎才真毁计划。

## 二、回归跑阶梯（退烧停药后严格执行）

1. **静息 24–48h 无烧 + 停退烧药后自觉正常** → 第一次出门：30–40min 平路 E，配速很慢，HR≤130，能整句聊天。
2. **连续 2 次轻松跑无复发**（无喉咙痛/乏力/静息心率异常高）→ 加一次质量课，量 −30~50%。
3. **再稳 2–3 天** → 回计划；长距当周按 **60–70%** 执行。
4. 任何症状回潮 → 立刻回退一级。
5. 病毒后 1–2 周，同样配速心率偏高 5–10 次（残余炎症/漂移）→ **按心率和体感跑，别硬顶配速**。

## 三、红绿灯

- 🔴 **立即就医**：烧 >39°C / 持续 ≥3 天 / 胸闷心悸 / 静息就气短 / 剧烈头晕
- 🟡 **回退一级**：任何症状回潮 → 只散步/全休
- 🟢 **可进阶**：连续 2 次轻松跑无复发 → 加质量课（量减）；再稳 2–3 天 → 回计划

## 四、你特有的体检红线（决策权重加倍）

| 项目 | 数值 | 对策 |
|---|---|---|
| 脂蛋白(a) | 678（0–300，遗传性） | 心内科随诊；运动中胸闷/胸痛/异常气短立即停 |
| 血小板 | 114（125–350，偏低） | **避免长期/大剂量 NSAID**（布洛芬/阿司匹林） |
| 间接胆红素 | 15.6 略高（Gilbert） | **禁空腹长跑**；强化补碳+按丢失补水 |
| 下肢静脉曲张（术后） | — | 长距后抬腿 15–20min、弹力袜；单侧小腿剧痛肿胀查 DVT |
| 心电图窦缓 | 59 | 良性；头晕黑朦/异常心悸就医 |

## 五、用药与恢复

- **退热优先对乙酰氨基酚（扑热息痛）**，遵说明书/医生；**避开 NSAID**（血小板低）。
- **带药状态不算"恢复"**：回归从停药后算起。
- **补水+碳水不能省**：风热感冒代谢高 + Gilbert 禁空腹，少量多餐、清淡好吸收。
- **蛋白保持 90–110g/天**（≈1.2–1.5g/kg，74kg）利于免疫修复。
- 静卧时小腿垫高 15–20cm 促静脉回流。

## 六、回归判读看什么

**晨脉 RHR + HRV 比"跑了没"更准**。例：9/27 跑了 4.28km（数据还失准），但 RHR 连续 4 天 52–54（基线 50）→ 仍炎症未清，不算恢复；9/29 RHR 49/HRV 56 → 才真正消退。
