# 体重下限规则与营养恢复

> 来源：2026-07 体检约束 + 2026-09 体重追踪（口报"斤"÷2）+ 双时点恢复技能。

## 一、体重下限规则（硬杠）

口报单位一律为"斤"，换算 kg 必须 **÷2**。

| 体重(kg) | 档位 | 动作 |
|---|---|---|
| ≥74.0 | 正常档 | 碳蛋常规档（碳 ~370g / 蛋 ~110g） |
| 73.0–73.9 | 警戒档 | 碳取上限 515g + 蛋 132g；**每周日晨起空腹称重**监控趋势 |
| 72.0–72.9 | 红线档 | 跑量增幅归零、必要时周跑量 −10~15% |
| <72.0 | 硬停 | 减量 20% 并排查非训练因素 |

趋势（2026 夏秋）：7/16 76.5 → 9/8 74.3 → 9/10 73.6（进入警戒）→ 9/11 74.55 → 9/14 76.35 → 9/18 74.2（连降 4 天约 2.15kg，仍≥74.0，警戒解除）→ 正常档。

**逻辑**：两月内掉重加速 = 有氧量+热量缺口双压；掉到警戒即把碳蛋顶满、加密称重，避免继续掉进红线/硬停。

## 二、双时点营养恢复

- **跑后 60min（A 窗）**：碳水 1.0–1.2 g/kg（≈75–90g）+ 蛋白 20–25g。快速补充肌糖原、启动修复。
- **下次训练前（B 窗）**：睡前补碳水 1.0 g/kg 助恢复；长距离后不拖到饭后才补。
- **蛋白总量**：90–110 g/天（≈1.2–1.5 g/kg，74kg），免疫修复与肌肉合成都需要。
- **Gilbert（间接胆红素略高）→ 禁空腹长跑**：必须吃碳水再出门，强化补水（按丢失补）。
- **水分**：长跑按出汗量补（高温天 ~760ml/h），少量多次。

## 三、静脉曲张护理（术后）

- 长距离后**抬腿 15–20min**（小腿垫高），促静脉回流、减轻胀。
- 弹力袜按需；放松由远端向近端推。
- ⚠️ **单侧小腿剧痛肿胀须排除 DVT，立即就医**（不可当普通酸痛硬扛）。

## 四、力量日安排（框架）

- 周五（长距离前一天）**必须减腿**：取消深蹲/弓步/单腿硬拉，改臀桥·蚌式·提踵 + 上肢核心。
- 感冒期轻量版：免腿负重、RPE 5–6、不憋气（见 docs/02）。
- 跑姿相关力量：提踵（缩短触地）、蚌式/臀桥（送髋）——直接对应对标短板（docs/04）。
