# 我的生活手册 · My Life Handbook

一个集中记录我的**工作、生活、爱好与习惯**的个人仓库，作为随身的「第二大脑」。

> 原则：先记下来，再慢慢优化。不要追求完美，追求「持续」。

---

## 这是什么

这里存放的是关于「我」的一切长期有价值的信息：

- 🗂 **工作** —— 目标、项目、复盘、技能清单
- 🏠 **生活** —— 健康、财务、日程、人际、清单
- 🎨 **爱好** —— 运动 / 摄影 / 音乐 / 手工……任何让我投入的事
- 🔁 **习惯** —— 每日例行、打卡追踪、月度回顾

---

## 目录结构

```
my-life-handbook/
├── README.md            # 本文件：总览与使用说明
├── work/                # 工作相关
├── life/                # 生活相关
├── hobbies/             # 爱好相关
├── habits/              # 习惯追踪与例行
├── templates/           # 可复制的模板（周/月回顾、打卡表）
└── .gitignore
```

每个一级目录里都有一份 `README.md` 说明「这里该记什么、怎么记」。

---

## 怎么用

1. **随手记**：有任何想法、灵感、决定，先丢进对应目录，别纠结格式。
2. **定期整理**：
   - 每天花 5 分钟更新 `habits/` 的打卡。
   - 每周用 `templates/weekly-review.md` 做一次周回顾。
   - 每月用 `templates/monthly-review.md` 做一次月回顾。
3. **保持轻量**：一个目录、一个文件、一段文字即可，先动起来。
4. **善用搜索**：内容多了之后，用 GitHub 的搜索（或本地 `grep`）快速找回记录。

---

## 维护约定（建议）

- 文件名用「日期-主题」或「主题」命名，例如 `2026-09-29-周回顾.md`、`阅读清单.md`。
- 中文为主，必要时中英混排。
- 不在这里放敏感明文（密码、密钥）；敏感信息用「见密码管理器」代替。
- 私有仓库，仅自己可见；如需分享某篇，单独导出即可。
