# 经验沉淀 / Experience

把「做过的事、踩过的坑、能复用的做法」集中在这里，作为个人知识库。
这是 `my-life-handbook` 里最有长期价值的部分。

## 写在哪

- 每条经验 = 一个文件，放本目录 `experience/`。
- 命名：`YYYY-MM-DD-主题.md`，例如 `2026-09-29-github建仓库.md`。
- 跨领域的也可按主题再分子目录（如 `experience/自动化/`、`experience/写作/`）。

## 怎么写（看 _template.md）

一条好的经验沉淀包含 5 段：

1. **背景** —— 当时要做什么、为什么。
2. **问题 / 卡点** —— 卡在哪、报错是什么。
3. **做法** —— 最终怎么解决的（关键命令 / 代码 / 步骤）。
4. **踩坑** —— 哪些路走不通、为什么。
5. **可复用结论** —— 下次直接照抄的结论 / 模板 / 命令。

## 怎么落库（三种方式）

- **A. 网页直接写**：在 GitHub 仓库页进 `experience/`，点 Add file 新建，提交。
- **B. 让我帮你写**：把经历口述给我，我整理成条目并用 API 推送到仓库。
- **C. 本地同步**：在本地 `my-life-handbook/` 里写，跑 `python3 sync_repo.py`（需 `GH_TOKEN` 环境变量）一键同步。

## 怎么查看 / 调用

- **查看**：GitHub 网页、或 `git clone` 后本地看、或 `gh search` 关键词检索。
- **调用（未来任务复用）**：做相关任务时告诉我「先查 my-life-handbook 里关于 X 的经验」，我用 GitHub API 拉取对应文件当上下文；也可把本仓库接入语义检索（如 ima 知识库）做全文/语义搜索。
